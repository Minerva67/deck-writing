# 发布前自查清单

## 整份 deck

- [ ] 三行写了：读者和场合、看完做的一件事、读者关心的结果。
- [ ] 分镜经用户确认过；或者用户明确说了直接做。
- [ ] 只读所有标题，能串成一段摘要。
- [ ] 同一个东西全文只有一个叫法（搜过一遍）。
- [ ] 同一个数字在各页一致。
- [ ] 称呼统一（全用「您」或全用「你」）。
- [ ] 有封面和封底；封面没有日期和过程说明；封底只有一个动作和联系方式。
- [ ] 具名的公司、合作方、案例都经用户确认；洽谈中的没有写成已合作。

## 每一页

- [ ] 只有一个结论。
- [ ] 标题是完整判断（展示类页面可用栏目名），30 字以内，没有模糊词。
- [ ] 遮住正文看标题，知道要相信什么；遮住标题看正文，能得出标题。
- [ ] 正文不超过约 220 字；能用图的地方没有用段落。
- [ ] 图的类型和数据的关系对得上（并列没有画成流程）。
- [ ] 全页只有一处强调色。
- [ ] 每个数字有来源、年份、定义；推算标了「推算」。
- [ ] 语言过了四原则：没有比喻、对仗、口号、口语词。
- [ ] 写的是读者得到什么。

## 渲染

- [ ] 渲染过，看了总览图。
- [ ] 标题没有断成孤字，没有超过两行。
- [ ] 没有文字溢出卡片、被裁掉或互相重叠。
- [ ] 没有大块空白，卡片没有空着下半截；每页内容占满七成以上。
- [ ] 正文字号在 26px 以上，没有整页都是 24px 的小字。
- [ ] 截图至少占半页，图上标出了问题位置。
- [ ] 没有连续几页用同一个文字框模板。
- [ ] 页面上没有分析方法、证据层级、所用模型这类过程说明。
- [ ] logo 都显示出来了，亮色 logo 看得清。
- [ ] 页码连续，和顺序一致。

## 发布和回复

- [ ] 发布前读过线上版，用户的手改都保留了。
- [ ] 回复里说了这次替换了哪些页。
- [ ] 回复里标出了哪些文案是新写的、哪些具名和数字待核对。
- [ ] 没渲染或没看线上版的，如实说明。
- [ ] 提醒了分享权限（要发给别人时）。
