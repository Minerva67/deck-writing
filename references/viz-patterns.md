# 按数据的形状选图

先问「这页要表达的是哪一种关系」，再选图。同一份 deck 里，同一种关系用同一种图。

| 要表达的 | 用什么 | 不要用 |
|---|---|---|
| 几项并列、没有先后（几种合作方式、几类人群） | 等宽卡片一排，或一张列对齐的表；不加序号和箭头 | 流程箭头、金字塔 |
| 有先后的步骤 | 编号卡片，按阶段分组；只在真的有先后时用 | 把并列项硬排成 01–05 |
| 几个方案在同一组维度上对比 | 表格：行 = 维度，列 = 方案；要强调的一列用浅色底 | 三栏文字段落 |
| 现状 → 方案 → 结果 | Before / After 卡 | 三栏挤在一张表里 |
| 逐级流失 | 连接条形图；把各环节乘出来的最终值放大写明 | 3D 漏斗、终点只写「?」 |
| 两个维度上的定位（成本 × 深度） | 2×2 象限，自己放在唯一的强调色位置 | 雷达图 |
| 多个痛点同一个原因 | 根因树：痛点 → 原因 → 汇到一处 | 并列的 bullet |
| 一两个关键数字 | 大数字 + 一行说明 + 来源 | 为了三个数字画柱状图 |
| 人群构成 | 类别卡 + 行业和角色关键词；或词云式的字号层级 | 说明句、粉丝数 |
| 人群或背书质量 | logo 墙，挂在对应那句话下面，末格写「等多家」 | 单独一面没有标题的墙 |
| 我方和同行逐项对照 | 表格：行 = 各家，自己单独一行并高亮；每格写具体做法 | 只写「有 / 没有」 |
| 案例 | 人物（行业 + 角色）→ 结果大字 → 卡在哪 → 怎么改 | 大段叙述 |
| 「对的人就在身边」这类洞察 | 场景示意图（一个房间、一条路线） | 抽象网络图 |
| 时间上的变化 | 折线或时间轴，只标关键节点 | 每个点都标数字 |

## 数字的画法

- 区间写下限，旁边标口径和来源。
- 负面数字（流失、成本上升）用警示色或描边，不用正面色。
- 一张图只强调一个点；其余退为灰或墨黑。
- 定性的图标「示意」。

## 一页放多少

- 卡片一排不超过 4 张；超过就分两行或拆页。
- 表格不超过 6 列、7 行；单元格里写短语，不写句子。
- 一页一张图。需要两张图说明同一件事时，左右并排、等宽。
